À obtenir avant d'arriver sur le poste (liste papier)
  • SSC : URL exacte (souvent https://…/ssc), un compte avec accès lecture aux applications visées, un jeton UnifiedLoginToken ou CIToken.
  • Réseau : proxy d'entreprise (HTTPS_PROXY) et, en cas d'erreur TLS, le certificat .pem de l'autorité interne.
  • Applications : la liste des groupes (APP.*) à auditer ; chaque sous-application doit avoir une version nommée exactement « release ».
  • Code : les dépôts clonés au commit correspondant à la release scannée.
  • Agent : OpenCode installé et déjà connecté au fournisseur GLM de l'entreprise (/connect).
  • Excel : le classeur d'audit (avec un onglet « Fortify »), ou rien : Paladin en génère un.
  • Concurrents : leurs exports (Excel, CSV, MD, SARIF) ; Paladin propose le mapping à valider.
